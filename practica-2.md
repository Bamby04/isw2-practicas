1. Git ayuda a guardar el historial de cambios en un proyecto.
2. Permite trabajar en equipo sin sobreescribir el trabajo de otros.
3. Con las ramas se pueden probar nuevas ideas sin dañar el código principal.
4. Los commits guardan avances con mensajes explicativos.
5. Los mensajes claros facilitan entender qué se cambió.
6. Los Pull Requests sirven para revisar el código antes de juntarlo.
7. La revisión de otros compañeros ayuda a detectar errores a tiempo.
8. GitHub permite almacenar el proyecto en la nube.
9. Trabajar con ramas mantiene el repositorio organizado.
10. Al terminar una tarea, la rama se une a la principal y se elimina.
11. Este flujo de trabajo es indispensable para programar en empresas.
